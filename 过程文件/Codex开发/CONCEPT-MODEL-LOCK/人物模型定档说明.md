# 概念画风人物模型定档说明

## 结论

人物外观不再由代码执行者依据文字重新设计。阳阳、爸爸的唯一权威形象，就是两张现有概念图中已经出现的人物。

- 人物身份、脸型、发型、泳帽、泳镜、眼镜、服装、身体比例与像素画法：以概念图为准。
- 动作姿态、动作相位、头身朝向、四肢关系、重心、时序、遮挡和双人接触点：以 FC 原版连续帧为准。
- 概念图中现有的水面、跳跃、水下平游和出水动作，只用来锁定人物在不同姿态中的形象稳定性，不作为后续动作证据。

本地权威审核板：`人物模型定档总表-本地勿提交.png`。该文件包含本地隐私参考裁片，不得提交、上传或嵌入正式游戏。

## 阳阳不可变特征

- 儿童圆短脸，大眼黑瞳并带高光，小鼻、小嘴、可见耳朵。
- 圆顶蓝色泳帽，具有深浅蓝分区和顶部高光。
- 白色完整泳镜框、两枚深色镜片、镜桥和绕头镜带。
- 蓝色泳装，紧凑的儿童体型，圆润且有体积的手、脚和四肢。
- 所有动作中必须保持儿童感；不得只靠蓝色辨认。

## 爸爸不可变特征

- 成年略长脸，高额头，露齿亲切笑。
- 短黑碎发，两侧明显收短；不得画成锅盖头、头盔头或平顶大色块。
- 黑色粗方框眼镜包住眼睛，保留镜桥、镜片、镜腿和可见瞳孔。
- 深色泳装，成年体型，整体高于且宽于阳阳。
- 所有动作中必须保持成年感；不得只靠黑色泳装辨认。

## 禁止的转译方式

- 禁止把概念图概括成“蓝帽儿童”和“黑发眼镜成人”后另画一套人物。
- 禁止用矩形、椭圆和直线重新拼出近似头像或身体。
- 禁止使用 Kimi 的 `CONCEPT-1A`、`CONCEPT-MODEL-0` 失败稿作为母版。
- 禁止为了适配动作而改变五官比例、发型、泳镜/眼镜和泳装结构。
- 禁止直接放大 FC 小人，也禁止把概念头像机械贴到 FC 身体。

## 后续动作转译公式

```text
概念图锁定人物形象
+ FC 原版连续帧锁定动作
+ 更高分辨率逐帧重绘
= 概念画风版 FC 动作
```

每个动作必须保留 FC 的关节角度、躯干轴线、头部朝向、重心、前后肢体层级、水面遮挡和接触关系。涉及肩组、拉脚、骑乘和挣扎的动作必须使用同一 pair anchor 进行成对绘制。

## 朝向与镜头透视硬合同

- FC 原版人物不是统一的横向侧身表现。后续不得因为概念图中存在横游姿态，就把游戏人物全部改成纯左侧脸或纯右侧脸。
- `L/R` 只表示动作或移动方向候选，不等于人物必须朝向屏幕左/右。移动方向、身体轴线、头部朝向和面向镜头角度必须分别记录。
- FC 帧中人物若面向镜头、背向镜头或呈斜前/斜后透视，新画风帧必须保持同一朝向，不得为了展示脸部而转成侧视，也不得为了复用概念横游图而把正面/斜前动作横向化。
- 水面、水下、跳跃、踢击、受击、肩组、拉脚、骑乘和挣扎都必须逐帧读取 FC 的近侧/远侧肢体、缩短透视与遮挡关系。
- 禁止仅凭 `flipHorizontal` 生成另一方向。镜像若改变脸部可见度、近远肢体、泳镜/眼镜高光或泳池透视，必须单独重画。
- 定档板中的水面、跳跃、水下平游和出水概念姿态只锁人物形象、比例和像素语言，明确不锁动作朝向。

每个后续动作帧至少记录：`sourceFrame / movementVector / bodyAxis / bodyYawToCamera / headYawToCamera / nearFarLimbOrder / waterlineOrDepthPlane`。缺少这些记录的帧不得进入人物绘制。

## 尺寸处理

本轮只锁人物设计，不用既有的低分辨率门槛反向简化人物。如果首次 FC 姿态转译在现有尺寸下无法完整保留定档特征，应提高运行时人物尺寸或重新验证场景比例，而不是删掉五官、发型、泳镜和肢体结构。
