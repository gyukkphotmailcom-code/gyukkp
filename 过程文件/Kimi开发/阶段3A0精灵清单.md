# 阶段3A-0 R2 精灵清单（完整人物精灵工艺验证）

> **已被用户视觉复核否决。** 本清单记录 R2 历史，不是可集成资产。R2 的
> `SURF0_BASE_SEGS/JUMP_BASE_SEGS/UW_BASE_ROWS + IDENTITY_RUNS` 只保证轮廓，
> 没有保证人体内部结构；新基线候选见 `阶段3A-R3A人体母版清单.md`。

本轮只验证 3 个原版姿态的制作工艺：`SURF0`、`JUMP_AIR`、`UW_NORMAL`。
3 姿态 × 2 人物 × 2 方向 = 12 张完整人物精灵。未接入主 HTML，未开始阶段3A-1。

## R2 的关键修正

- 保留 Kimi 已完成并可验证的 `SURF0`、`JUMP_AIR`。
- 废弃旧 `UW_NORMAL`：0基帧 f15625 的 65×22 裁剪同时包含两名接触角色，不是单人精灵。
- 新 `UW_NORMAL` 使用美版视频 0基 f12490 的单人、无遮挡横泳姿态；同景空背景 f12504
  做逐像素差分，得到 34×18 的一体化人物轮廓。
- 阶段2的 24×24 `FACES` 只提供身份特征像素，不再整块粘贴为动作头部。
- `mask_*.png` 与 JSON、原始裁剪、来源 SHA、帧号、裁剪框均强校验；默认构建不依赖原版视频存在。
- 水面遮挡修正为 3942 个真实前景像素；不再导出全零的 `waterOcclusion`。
- 审核表每格只含严格原生 1× 和一次 `NEAREST` 8×，不做 fit、拉伸或二次缩放。

数据源：`build_sprites_3a0.py` + 已批准的 `avatar_paint.py` + `阶段3A0参考/` +
`阶段1截图.png`。运行时候选数据为 `sprites_3a0_baked.js`，但本轮禁止接入主程序。

## 姿态清单

### SURF0（水面俯泳）

- 尺寸：31×21；有效像素：450；可见 bbox：`[0,0,30,20]`
- `rootByDir`：L `[15,10]` / R `[15,10]`（身体中心）
- `identityMask`：阳阳 66/450=14.7%；爸爸 45/450=10.0%
- 排除身份区后的几何：XOR 1/384=0.3%，最大边界偏差 1px；门槛 10%/1px
- 来源：日版官方 `jp-action-e.gif` 人物原生裁剪；美版 f12393 仅作场景比例辅证

### JUMP_AIR（空中飞扑）

- 尺寸：55×42；有效像素：1383；可见 bbox：`[0,0,54,41]`
- `rootByDir`：L `[24,41]` / R `[30,41]`（各方向真实脚底中心）
- `identityMask`：阳阳 148/1383=10.7%；爸爸 95/1383=6.9%
- 排除身份区后的几何：XOR 4/1239=0.3%，最大边界偏差 1px；门槛 10%/1px
- 同世界 root 下左右脚点不跳；bbox 中心相对语义脚锚偏移 6px只是信息指标，不能为追求中心
  对称把脚锚重新放回透明点或人为加宽脚底
- 来源：日版官方 `jp-action-c.gif` 人物原生裁剪；只能证明该空中姿态，不能证明完整跳跃时序

### UW_NORMAL（横向水下）

- 尺寸：34×18；有效像素：369；可见 bbox：`[1,1,32,16]`
- `rootByDir`：L `[17,9]` / R `[16,9]`（身体中心）
- `identityMask`：阳阳 65/369=17.6%；爸爸 67/369=18.2%
- 排除身份区后的几何：XOR 0/304=0.0%，最大边界偏差 0px；压缩源门槛 15%/2px
- 主证据：美版视频 0基 f12490，06:56.333，安全裁剪 `(129,107,163,125)`；人物可见
  bbox 为 abs x130..161/y108..123，源朝右，严格水平镜像为 canonical L
- 背景证据：同景空背景 f12504；差分阈值为 RGB 最大通道差 ≥25，取最大4连通体，
  不填洞、不平滑、不拉伸
- 辅证：f12493 同一动作另一相位；f15600 另一干净单人实例
- 明确作废：f15625 `(60,114,125,136)` 的旧65×22双人合体裁剪和由此产生的身体数据

## 身份、调色和方向

- 身份像素全部从已批准 `FACES[who][dir]['正常']` 逐段复制；`avatar_paint.py` SHA-256
  固定为 `615daea6…b1194e`。
- 阳阳保留蓝泳帽/泳镜，爸爸保留棕发/眼镜；两人身份区外像素差异全部为 0。
- 水下 `UW_MAP`：深青/中青/浅青/白四档，不使用半透明蓝色蒙版。
- `SURF0/JUMP_AIR` 的 R 向身体是 L 向镜像候选；`UW_NORMAL` 则相反：原版直接证据
  为 R 向，canonical L 由该 R 向水平镜像派生。三者都尚无另一方向的独立原版轮廓证据，
  因此未被直接取证的方向保持 TBD。

## 水面遮挡

- 输入：SHA 固定的 `阶段1截图.png`，768×672 最近邻还原为 256×224。
- y72..101 的泡沫白/浅波纹作为前景遮挡：共 3942px、30行，其中29行非空。
- `waterOcclusion.rows` 采用相对 y=0..29 编码，经过 decode roundtrip 和像素数断言。
- `阶段3A0场景验收图.png` 为 256×224；`阶段3A0场景验收图-8x.png` 为严格最近邻局部。
