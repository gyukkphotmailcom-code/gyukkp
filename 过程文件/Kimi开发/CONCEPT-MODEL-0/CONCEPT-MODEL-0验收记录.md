## 4. 新标准稿与概念图逐项对照说明

因两张概念图属家庭隐私素材（“本地勿提交”），对照表只能以文字描述，不能贴入概念图裁片：

- 阳阳帽上泳镜位置：概念图为“泳镜架在帽前、白框藏青镜片、白带绕头”，本稿四向均按此绘制；侧视退化为单镜片+镜带，与概念图多动作稿中的侧视一致。
- 爸爸眼镜：概念图为“黑粗方框、镜框包住眼、镜腿到耳、镜片浅、可见瞳”，本稿按此绘制。
- 爸爸发型：概念图为“顶部短碎发、高额头、两侧剃短渐变露头皮色”，本稿用实心顶部+质感像素+渐变短茬表达。
- 体型：概念图中爸爸明显高于/宽于阳阳但同为 Q 版；本稿 78 vs 65px、头身比 2.69 vs 2.41。
- 肤色：概念图两人同暖肤色、右侧受影；本稿共用 SKIN 系、右下侧肤影。

## 6. 已知弱点（如实列出）

1. 爸爸正面头顶发际线较平直，靠两个微凹点和侧部渐变避免“头盔感”，是否足够需人工判断。
2. 阳阳侧视泳镜为“白框+藏青镜片”的矩形块，1x 下镜框白色占比偏高。
3. 爸爸侧面全身的眼镜在 1x 下是头部前缘的小黑块，镜腿细线可读性一般。
4. 正面全身稿的双手为椭圆“圆手”，无手指，与概念图一致但在 1x 下与手腕连接处略粗。
5. 灰度盲审表中两人身高差本身是最强线索，盲审主要验证“结构特征是否足够区分”，不代表游戏中会有灰度场景。
